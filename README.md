# 🚀 CodeForge - Frontend Learning Platform

![CodeForge Banner](./assets/images/banner.png)

CodeForge is an interactive frontend learning platform designed to help beginners learn and practice **HTML, CSS, and JavaScript** through hands-on coding, challenges, and a live coding playground.

The goal of CodeForge is to provide a simple environment where learners can write code, experiment, and instantly see the output.

---

## 🌟 Features

### 💻 Live Code Playground

- Write HTML, CSS, and JavaScript code
- Execute code instantly
- View live output using an integrated preview window
- Reset editor with starter code
- Supports keyboard shortcut:
  - `Ctrl + Enter` → Run Code

---

### 🧩 Frontend Challenges

- Practice frontend concepts through coding challenges
- Challenge cards dynamically generated using JavaScript
- Helps learners improve problem-solving skills

---

### 📚 Learning Features

- Beginner-friendly frontend learning approach
- Covers:
  - HTML fundamentals
  - CSS styling
  - JavaScript concepts
  - DOM manipulation

---

### 🎨 Modern User Interface

- Responsive design
- Smooth scrolling navigation
- Interactive hover effects
- Typing animation
- Clean dark theme UI

---

## 🛠️ Technologies Used

# HTML5  - Website structure 
# CSS3 - Styling and animations 
# JavaScript - Interactivity and dynamic features
# DOM API - Dynamic content manipulation
# iframe - Live code execution preview

## ⚙️ How To Run Locally

1. Clone the repository

```bash
git clone https://github.com/yourusername/CodeForge.git

2. Go to the project folder

```bash
cd CodeForge

3. Open index.html in your browser.

```

## Working

User writes code
        |
        ↓
JavaScript captures input
        |
        ↓
HTML + CSS + JS combined
        |
        ↓
Rendered inside iframe
        |
        ↓
Live preview displayed

```
